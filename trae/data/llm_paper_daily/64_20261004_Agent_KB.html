大模型经典论文精读系列 #064

想象一位在三甲医院干了二十年的外科主任跳槽到邻市医院：第二天他就能上手术台——因为经验长在人身上。可 agent 的世界恰好相反：一个在 smolagents 框架里练出一身"分步拆解网页搜索"本领的 agent，搬进 OpenHands 就变回实习生；SWE-Agent 上周修过的那类 bug，隔壁框架的 agent 连听都没听说过。经验不长在"医生"身上，而是焊死在"医院的挂号系统"里——换个楼，一切清零。

上一篇 ReasoningBank（#063）我们开了一家"记忆银行"，但存折上只有一个人的名字。文末留了个悬念：如果给所有 agent 开一家"中央银行"，让经验跨领域、跨框架自由流通，会发生什么？这一篇就是答案。而且答案的作者阵容本身就是一条行业新闻：MetaGPT（#038）、AutoGen（#039）、OpenHands（#049）的创始人们坐到了同一张桌子前。更有意思的是，他们很快发现光"共享"还不够——随手借来的经验会把 agent 带进沟里，于是论文干脆发明了一道"分歧门"。

一句话总结 给所有 agent 开一家"中央知识银行"：任何框架的 agent 干完活都把经验存进去，接新活的任何 agent 都能取出来用——不重训、不改架构、插上 API 就变聪明；再配一道"分歧门"，只放行那些帮忙不添乱的经验，让集体智慧安全复利。

01领域定位

把这个系列最近十篇连起来，一条主线已经非常清晰：agent 如何不靠人喂数据，自己攒本事。Absolute Zero 让模型自博弈出题（#055），OpenSkill 到 MUSE-Autoskill 一路把"技能"从网上海选做到沉淀传承（#059–#061），WikiSkill 把经验编译成一本永不回滚的维基（#062），ReasoningBank 把成败轨迹蒸馏成"记忆存单"、在测试时越用越聪明（#063）。

但这条线上的所有工作，都有一个没说出口的前提：经验只属于一个 agent、一个系统。ReasoningBank 的存折上写的是一个人的名字；WikiSkill 的维基是单机版百科。Agent KB 把这个前提掀了：它不问"一个 agent 如何记住"，而是问"一群各自为政的框架，如何共享记忆"。这是"经验复利"叙事从个体走向集体的关键一跳——上一代工作证明经验可以沉淀，这一篇证明经验可以流通。用论文自己的话说，它要为"集体智能"（collective intelligence）打下第一块地基。

02研究背景

2023 到 2025 年，agent 框架迎来大爆发：HuggingFace 的 smolagents 走轻量路线，Princeton 的 SWE-Agent（#047）专注修 bug，All Hands AI 的 OpenHands（#049）做全能软件工程师，CAMEL-AI 团队（CAMEL 就是我们在 #040 读过的那篇）长出了 OWL。每家框架都在实战里积累了大量宝贵的解题经验——但论文开头就点了要害：这些经验被困在各自的系统里（trapped within individual systems）。浏览器专家攒的网页经验，代码助手用不上；A 框架踩过的坑，B 框架原样再踩一遍。

已有的记忆系统也帮不上忙。论文把前人工作盘了一遍：MemoryBank、MemGPT、A-Mem、Synapse、Agent Workflow Memory……结论是几乎全部停留在"单 agent"或"单框架"的记忆，无法跨架构迁移。作者们进一步归纳出三大设计缺陷：

  • 任务经验隔离（task-specific experience isolation）：经验绑定在特定任务类型上，换个领域就从零开始；
  • 单一检索粒度（single-level retrieval granularity）：规划阶段需要"高层打法"，纠错阶段需要"细粒度补丁"，用一套检索对付两种需求，两头都做不好；
  • 静态经验回放（static experience replay）：原样存、原样放，不做抽象——可原始日志里的细节换个环境就失效，真正能迁移的是抽象出来的原则。
类比 这就像每个小区自建水塔：家家有水喝，但水质参差、重复建设，还装不了净水设备。Agent KB 的主张是——建一个自来水公司：统一取水（标准化经验格式）、统一管道（轻量 API）、统一水厂（共享知识库），全城喝同一张网的水。谁家水厂先建好，谁就定义了行业标准。

03核心问题

于是问题被拆成两问，一明一暗：

明的问题：怎么让架构完全不同的框架共享经验，而且不重训练、不改框架代码——像插 USB 一样即插即用？暗的问题：借来的经验如果"水土不服"，把 agent 的正确思路带偏了怎么办？作者管这叫"知识干扰"（knowledge interference）——这个问题论文初版里还没有，是在一次次实验里被撞出来的，后来干脆升格为正文的核心设计。

思考一下 把 A 框架攒的经验直接塞给 B 框架的 agent，你觉得最先坏在哪一步？提示：两个框架里连"工具"的名字都不一样——一个叫 search_web，另一个叫 web_search。照抄别人的操作序列会发生什么？先想 30 秒，再往下看。

04方法详解

Agent KB 的完整系统可以拆成四件事：存什么（经验长什么样）、怎么管（知识库如何自进化）、怎么传（跨框架的管道）、怎么用（两阶段取用 + 一道保险门）。全程不碰模型权重——它是一个挂在 agent 身边的"外挂记忆设施"。

第一步 · 存什么：不存日志，存"打法"

原始执行日志又臭又长——工具调用、报错、重试，90% 都是只对当时那个环境有意义的噪音。Agent KB 的选择是只存抽象后的经验：每条经验被蒸馏成一个结构化元组——

$$E=\langle\pi,\gamma,S,\mathcal{C}\rangle$$ (1)

用医院做类比：π 是"病人画像"（任务的语义嵌入，用 all-MiniLM-L6-v2 编码），γ 是"治疗目标"（结构化的目标约束），S 是"诊疗方案"（一串"行动—理由"对：做了什么、为什么这么做），C 是"病历首页"的元数据（领域、难度、所用工具、来源框架）。急诊科从不保存监护仪的原始波形，保存的是"主诉—诊断—处方"——那份病历才是能转院的东西。

经验从哪来？论文的构造流程是一场"人工点火、机器烧柴"：5 名计算机专业研究生先手写 80 条高质量"种子经验"（60 条浏览式、20 条编码式），作为 few-shot 范例去提示大模型，对 BrowseComp、MultiHopRAG、HLE、WebWalkerQA（通用推理）和 RepoClassBench、SWE-Gym、RepoEval（软件工程）七个数据集的轨迹批量蒸馏，最终攒出约 9,000 条工作流摘要 + 7,000 条执行片段。一个值得点赞的细节：他们刻意把 HLE 的生物化学子集从经验源里剔除、留作考题——自己不喝自己考卷里的墨水，防的就是数据泄漏的嫌疑。

第二步 · 怎么管：知识库的自进化

记忆库不是仓库，堆到一定规模就会"变异"。Agent KB 配了两个管理员：查重员——新经验入库前先算与库内经验的语义相似度，超过 0.8 就算"疑似重复"，交给一个 LLM 裁判从推理质量、完整性、可迁移性三方面打分，只留更好的那条；清退员——每条经验维护一个效用分，按最近是否被成功取用来更新：

$$u_j \leftarrow u_j + \eta\,(r_j - u_j)$$ (2)

这是一个指数滑动平均：最近老被成功取用的经验分数上涨，长期没人取的旧经验分数阴跌，跌破线就腾出位置。还是那个图书馆的比喻——好书越摆越靠前，落灰的旧书定期剔旧下架，书架永远留给还活着的知识。

第三步 · 怎么传：框架无关的插头

跨框架共享听起来简单，实则处处是方言。Agent KB 的解法朴素而有效：定义一套统一的经验 schema（就是上面的四元组），再把它包进轻量的 REST/RPC 端点。任何框架只要能发 HTTP 请求，就能"存"与"取"——agent 本体一行代码不用改，模型一个权重不用动。这就是它敢自称"即插即用"（plug-and-play）的底气，也是 USB-C 的逻辑：接口标准化之后，设备厂商各自为政的线缆战争一夜休兵。

这根管还带来一个乘数效应：论文的实验里，四个框架接的是同一个 Agent KB 实例——smolagents 存进去的经验，OpenHands 一秒后就能取到。存款的人越多，取款的人越赚，典型的网络效应。

第四步 · 怎么用：两阶段 Reason-Retrieve-Refine + 分歧门

取用不是"查到就抄"。Agent KB 在一次任务的两个时机各介入一次，每次都跑一遍"推理—检索—改编"三步循环（Reason–Retrieve–Refine）：

规划阶段（考前）：新任务进来，先 Reason——分析任务需求与潜在坑点，生成结构化查询；再 Retrieve——用混合检索找老经验：BM25 词法匹配保"精确对题"（工具名、领域词都算分），语义嵌入保"触类旁通"，两路分数加权融合后取 top-3：

$$\sigma^{\text{hyb}}_i \leftarrow \alpha\cdot\tilde{\sigma}^{\text{text}}_i + (1-\alpha)\cdot\tilde{\sigma}^{\text{sem}}_i,\qquad \alpha=0.5$$ (3)

最后 Refine——把别人的打法翻译成本框架可执行的方案：实体映射（旧经验里的变量名换成当前任务的）、工具替换（search_web 换成自家的 web_search）、步骤重排（按领域约束重排顺序），输出一份可执行计划。还记得思考题吗？最坏就坏在这一步之前——照抄操作序列必然工具名对不上、上下文对不上；改编，才是检索的下半场。

反馈阶段（考后）：第一轮执行完，Agent KB 再介入一次。这次 Reason 的对象不是任务描述而是执行轨迹——找错、找瓶颈、找意外；Retrieve 检索的不是"怎么解题"而是"怎么修正这类错误"的补丁型经验；Refine 出一份修订计划。但修订计划不能直接上——这里站着论文最出圈的发明：分歧门（disagreement gate）。

$$\mathcal{G}(\rho,\rho')=\mathbb{1}\!\left[\,\cos\big(\phi(\rho),\phi(\rho')\big)\ge\beta\right],\qquad \beta=0.8$$ (4)

翻译成人话：原计划 ρ 和修订计划 ρ′ 各算一个语义向量，余弦相似度过 0.8 才放行，不过线就拒收。像导师审学生的修改稿：如果"修改建议"把论文改得面目全非，那说明这建议根本不是为这篇论文准备的——是另一篇论文，退回。检索来的经验在嵌入空间里离你原来的思路太远，大概率不是"帮你"而是"带偏你"：这就是论文说的知识干扰，分歧门就是防它的柜面风控。

05实验结果

实验规模在"记忆系"论文里算得上豪华：4 个基准（GAIA 165 题通用助理、HLE 生物化学 149 题人类最后考试、GPQA 198 题博士级问答、SWE-bench Lite 300 个真实 GitHub issue）× 4 个框架（smolagents、OWL、SWE-Agent、OpenHands）× 6 个底座模型（GPT-4o、GPT-4.1、Claude-3.7、o3-mini、Qwen-3 32B、DeepSeek-R1）。

先解释一个容易误会的记号：这里的 pass@1/2/3 不是"采样三次"，而是三轮成长——pass@1 是首考（用库里已有的跨任务经验）；pass@2 把第一轮的失败诊断写回知识库再战；pass@3 用扩容后的库死磕未解之题。本质是上一篇文章"错题本"机制的集体版：库越战越厚，越战越准。

数字相当能打：smolagents 配 GPT-4.1 在 GAIA 上从 55.2% 一路涨到 73.9%（+18.7 个百分点），配 Claude-3.7 涨到 75.2%，L3 最难题档从 38.5% 拉到 57.7%；换到代码战场，OpenHands 配 Claude-3.7 在 SWE-bench Lite 上首考就 +16.7，三轮后 50 轮预算下冲到 51.0%（+21.0）。科学考场同样灵：HLE 生物化学上 OpenHands 从 9.5% 涨到 14.1%（pass@3），反超专门搞科学 agent 的 Biomni（10.7%）；GPQA 上 GPT-4.1 从 62.6% 涨到 72.7%，直逼 o3-mini 的裸考成绩。而且所有底座都涨——开源的 Qwen-3 32B、DeepSeek-R1 也一样，不存在"只聪明的模型才配用"的门槛。

发现一：改编才是护城河。把 Refine 砍掉，增益归零；不做抽象、直接回放原始工作流也只剩一半。检索谁都会做，把别人的打法翻译成自己的动作，才是这套系统里最值钱的一步。发现二：机器蒸馏 ≈ 人工手写，难题上反超。GAIA 上自动生成的经验拿到 75.15%，对五名研究生手写的 76.97% 几乎打平；而 L3 最难题档上自动经验反超手写（57.69% vs 53.85%）——机器归纳的"打法"比人写的更不啰嗦、更敢迁移。发现三：错误是净减少的。错误分析里数了个账：GPT-4.1 借助 KB 修好了 25 个基线错误，只引入 15 个新错误，净减 10 个；检索类错误从 24 降到 20，规划类从 13 降到 10——外挂经验没有"按下葫芦浮起瓢"。发现四：几乎不要钱。一轮完整 GAIA 评测总开销约 86 美元，Agent KB 的检索环节只加 0.27 美元（不到 0.4%）；SWE-bench 上每题摊销不足 0.4 美分。

06影响与意义

Agent KB 最直接的影响，是把一个此前只停留在"愿景"层面的命题第一次做成了可复现的系统：跨框架、即插即用、零重训练的经验共享。它拿下 ICML 2025 CFAgentic Workshop 最佳论文亚军（Oral），也成了"记忆基础设施"这条新赛道的参照系——A-Mem 系的图结构记忆、MemOS、MIRIX 等一批同期与后续的记忆基建工作，几乎都在它框定的问题域里展开：经验的标准化表示怎么做、跨框架协议长什么样、检索分几层。

更深远的意义在于它改变了"记忆"的产权属性。此前记忆是模型的私有物（长在权重里）或 agent 的私有物（长在会话里）；Agent KB 之后，记忆第一次成为公共设施——像从"家家自备发电机"走向"接入电网"。顺带，它还把"框架之争"的战场悄悄前移了一格：当任何框架都能接同一个记忆库时，框架本身的护城河变浅，记忆协议的制定权浮出水面。2025 年之后各主流框架陆续把"外部记忆 / 上下文管理"列为官方组件，多少印证了这个判断。

07局限性与未来方向

论文自己交代的和实验数据里藏着的，至少有这么几条：

  • 代码域的自动蒸馏还没追上人类：GAIA 上自动经验打平手写，SWE-bench 上却仍有差距（51.0% vs 55.7%）——代码经验的"可迁移抽象"比通用推理更难自动提炼；
  • 治理是空白：分歧门只管"取"这一侧的风控，"存"这一侧没有验钞机——谁对写入经验的正确性负责？错误经验一旦入库并流通，比错误参数更顽固（参数会被下次训练冲掉，坏存单会一直被检索到）；
  • 检索仍是最大瓶颈：错误分析里检索类错误只是从 24 降到 20，仍是第一大错误类别；知识库规模消融也显示，高阶推理任务的收益对库的规模几乎无感——卡的是质量，不是数量；
  • 难题吃不到首轮红利：L3 任务在 pass@1 上常常零增益，要等两轮"错题本"写回才见效——这种模式对一次性的真实部署并不友好；
  • 静态基准 vs 真实世界：论文按自己的说法，未来要做"更丰富的模态与更长时程"——潜台词是：现在的经验库还是纯文本的，也还只在基准测试里转。

08领域演进脉络

把这个系列连起来看，"记忆"这条支线的谱系已经完整浮现：Voyager（#036）在《我的世界》里攒出第一本"技能图书馆"；Experiential Co-Learning（#042）让历史轨迹可复用；WikiSkill（#062）把经验编译成可生长的维基；ReasoningBank（#063）证明了"失败存单"的价值、并给出零训练的测试时复利；今天这篇 Agent KB 则完成了从"个体记忆"到"集体记忆"的关键一跃——经验不再属于某个 agent，而属于接入协议的所有人。

再放大到整个系列的脉络：奠基期的 Transformer（#001）给了"计算"以骨架，预训练范式期（#002–#003）给了"知识"以来源，规模化探索期（#004–#005）给了"能力"以曲线，对齐与应用期（#006）教会模型听话、推理范式期（#013–#023，#024 起 CoT 家族）教会模型思考、agent 家族（#035 起）教会模型动手、自博弈与技能沉淀（#054–#061）让模型自己攒本事——而经验复利期（#062 至今）正在回答：攒下的本事如何变成整个生态的公共资产。Agent KB 站在这条线的正中间，往后看是 WikiSkill 们的单机账本，往前看是"集体智能"的电网雏形。下一步？电网之上还需要调度系统——这正是下期预告的伏笔。

09趣味延伸

这篇论文最好玩的注脚，全在作者名单里。队列中站着 Sirui Hong——MetaGPT（#038）的创始人；Chi Wang——AutoGen（#039）的作者；Xingyao Wang——OpenHands（#049）的发起人；还有 MetaGPT 团队的 Chenglin Wu、Wangchunshu Zhou 和 Google DeepMind 的 Hao Cheng。换句话说：agent 框架的"军火商们"坐下来签了一份军控条约——自家框架的独门经验，从此共享。被测的四个框架里，OWL 正是从我们读过的 CAMEL（#040）团队里长出来的，SWE-Agent 是 #047、OpenHands 是 #049——连续剧读到这里，配角全数到齐。

还有几枚彩蛋。其一，资助方是 OPPO——一家手机厂商悄悄投资了这场 agent 基础设施实验，机构列表里 "OPPO" 的圆圈标记一路跟在三位共同一作名字后面。手机厂大概最懂"生态"两个字怎么写。其二，时序彩蛋：一作 Xiangru Tang（Yale 博士生，此前刚拿过 IJCAI 2024 的 workshop 最佳论文）——正是上一篇 ReasoningBank（#063）的一作。但细看时间戳会发现一个倒叙：Agent KB（2025 年 7 月）其实写在 ReasoningBank（2025 年 9 月）之前。也就是说，我们上一篇读的是他的"续作"，今天这篇才是"前传"——一个研究者的两条分支：一条做个体记忆的零训练复利，一条做集体记忆的跨框架流通，最后在"经验"这个母题上会师。

其三，这篇论文自己的"错题本"也很有戏。7 月初版在 ICML workshop 拿奖时，标题还是 A Hierarchical Memory Framework，讲的是一个人格化的故事："学生 agent 先做题，老师 agent 批改"。随后四个月连改五版（v1 到 v5），师生设定被抽象成冷峻的 planning/feedback 两阶段，补上了分歧门，框架适配从一个扩到四个，基准从两个扩到四个——终稿标题里的 "Leveraging Cross-Domain Experience" 才落定。一篇讲"经验复利"的论文，自己也在靠版本迭代复利，算是一种行为艺术。

最后一个具体到可爱的案例来自初版的开篇：读蛋白质结构文件（PDB）算两个原子的距离。基线 agent 无脑抓文件前两行，结果抓到的是溶剂记录，算出 0.961 埃的"氧—氢键"；挂上 Agent KB 的 agent 按老经验的打法走——过滤掉 ANISOU/HETATM 行、只取真正的 ATOM 记录、用 N–CA 键长的常识范围做健全性检查——得到 1.456 埃的正确答案。注意这里的老经验不是"这个文件怎么读"，而是"这一类文件该怎么读"：经验的迁移性，恰恰来自对细节的抽象。这是全文论点最小也最完美的一次演出。

10个人解读与延伸思考

算一笔经济学账：一轮 GAIA 评测 86 美元，检索只加 0.27 美元，换来 +18.7 个百分点。参数缩放的一次 Pretraining 以千万美元起步，算力缩放按 token 收费，而经验缩放的边际成本趋近于零——因为它的原料（执行轨迹）本来就是生产过程的废水，不回收就白白流走。但 Agent KB 提醒我们一个常被忽略的前提：经验免费的前提是流通。废水不接管道，永远只是废水；接了管道，就是下一代人的自来水。

再想深一层，"中央银行"的比喻在上一篇的思考题里已经出现：当记忆可以流通，假钞（恶意/错误经验）能不能注资污染整库？Agent KB 给出的答案是半套：REST API 是账户体系，分歧门是柜面风控，效用清退算是坏账核销——但银保监会依然缺席。分歧门防的是"取错"，不防"存假"：一条精心包装的错误经验只要过了 0.8 相似度门，反而会被"高信用"地反复取用。下一篇做记忆治理的人，大概率要从这里开挖。

最后是一个商业视角的推演。你是框架作者，你愿意把用户的执行轨迹喂给公共 KB 吗？存进去，全行业变强，你的独门优势被摊平；不存，你错过复利，竞争对手的用户经验照样入库。这是标准的囚徒困境，而这篇论文用作者名单给出了部分答案——MetaGPT、AutoGen、OpenHands 的创始人们用行动投了票：在生态早期，做基础设施的人拿走最大的那份。当年开源 Transformer 的 Google、开源 LLaMA 的 Meta，走的都是同一条路。

留个问题给你 如果未来真出现"记忆市场"——高手 agent 的成功经验可以挂牌定价、按次取用——你愿意买谁的经验？定价又该按什么算：按它当年任务的成功率，还是按它在你任务上的可迁移性？再狠一点：如果一条经验的"疗效"取决于取用者自己的水平（强者取之如甘露，弱者取之如毒药），这个市场还有统一定价的可能吗？把你的答案留给下一篇——因为很快，会有人把"记忆"本身做成操作系统，而操作系统里永远绕不开两个问题：资源怎么调度，价格怎么标。

MemOS: A Memory OS for AI System（MemOS：给 AI 装一个"记忆操作系统"——当记忆像内存一样被调度、被换页、被计价）

Agent KB 把"中央银行"开了起来，但一家银行撑不起一整套金融体系：参数权重、KV 缓存、外挂文本是三种完全不同的"货币"，汇率怎么定？谁来记账、谁来做风控、谁来调度？下一篇，记忆张量、上海交大、中国人民大学等十余家机构组成的"国家队"干脆掀了桌子——把记忆做成操作系统 MemOS：记忆不是外挂的文本库，而是一等公民，像操作系统调度内存那样被统一调度、换页与计价。LLM 的"Windows 时刻"，会从这台记忆操作系统开始吗？下期见分晓。
