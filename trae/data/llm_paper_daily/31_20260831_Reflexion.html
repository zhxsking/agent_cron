大模型经典论文精读系列 #031

Reflexion: Language Agents with Verbal Reinforcement Learning Reflexion：把每次失败写进"语言记忆"——靠外部反馈信号撑起真正的"言语强化学习"，让自我纠正走出纯内在循环

作者：Noah Shinn, Federico Cassano, Edward Berman, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao 机构：Northeastern University · MIT · Princeton University 发表：2023-03 / NeurIPS 2023
arXiv GitHub

上一篇我们刚听完一句让人有点泄气的结论：没有外部反馈、纯靠模型自己审自己，LLM 越改越糟。如果内在自我纠正是一条死胡同，那"自我纠正"这件事是不是就此被判了死刑？东北大学的 Noah Shinn 和普林斯顿的 Shunyu Yao（对，就是 ReAct 的那位 Yao）显然不甘心。他们沿着同一片战场往前走了半步，给出了一个朴素到近乎狡黠的回答——

既然问题出在"没有新信息进入"，那就给它新信息。但不是用昂贵的强化学习去重写模型的权重，而是用一种几乎零成本的方式：让 agent 把"这次为什么失败"用自然语言写成一段反思，存进一个记忆本子，下一轮带着这条教训再试一次。这，就是 Reflexion。它在 HumanEval 上把 GPT-4 自己的 80% 干到了 91%——套着 GPT-4 的壳，竟然打败了 GPT-4 本身。

一句话总结 不更新任何权重，只让 agent 把每次失败浓缩成一段"反思笔记"塞进记忆，下一轮带着这条教训重试——Reflexion 用"外部反馈 + 语言记忆"把自我纠正从纯内在循环里救了出来，在编程任务上让 GPT-4 的 pass@1 从 80% 飙到 91%。

01领域定位

要看懂这篇论文的位置，得把它放回我们这条"自我纠正三部曲"里。第 29 篇 Self-Refine 把"自我批评"当成无需训练就能用的提示工程法宝，开篇立论；第 30 篇 Cannot Self-Correct Reasoning Yet 把这块招牌砸了，指出纯内在自我纠正的增益其实是偷偷塞了标准答案在作弊。那么问题来了：自我纠正这条路，到底还能不能走？

这一篇就是那个回答：能，但得换条腿走路。不能靠"同一个脑子审同一个脑子"的内在循环，得靠外部反馈——环境告诉你对没对、单测跑没跑过、搜索查到没查到——然后把这些外部信号翻译成一段自然语言的"反思"，存进一个可编辑的长期记忆。它正好卡在两条线索的交叉口：往回看，它是 ReAct（Yao 等人 2022）这条 agent 主线的直接延续，作者都有 Shunyu Yao；往前看，它把"外部反馈自我纠正"这条新路彻底走通，直接喂出了后来一整波 agent 论文——CRITIC、Voyager、Self-RAG 都站在它肩膀上。

02研究背景

2022 年到 2023 年初，"LLM agent"成了最热的词。ReAct 让模型交替输出"思考"和"动作"，Toolformer 教模型自己学会调工具，HuggingGPT 把一整套模型串起来干活，generative agents 让 25 个虚拟小镇居民在沙盒里过起了日子。这些工作证明了一件事：把 LLM 当成"大脑"，外面套一层能调用 API、能跑代码、能看环境的躯壳，agent 真的能动起来。

但它们都有同一个致命短板：不会从失败里学。一个 ReAct agent 这次走错了房间、写崩了代码，下一次同样的任务它还会走错、还会写崩——因为它的"工作记忆"只活在当前这一回合的上下文窗口里，回合一结束，上下文一清空，经验就蒸发了。本质上，这些 agent 只是"带着环境交互的、一次性的评估任务"，没有试错学习的能力。

那为什么不直接套传统强化学习？作者列了三条硬伤：LLM 参数太大，在线微调又贵又不稳；标量 reward 信息量太少，复杂任务里根本分不清是哪一步错了（信用分配难题）；而且白白浪费了 LLM 已经很强的规划、分析能力——传统 RL 把模型当黑盒只看 reward，等于让一个会写诗的人去搬砖。

类比 想象一个失忆的主厨。他今天把汤熬咸了，客人骂了一顿；可他第二天醒来什么都不记得，照样放一大勺盐。传统 RL 的解法是"重接他的神经"——动手术改写大脑连接，让他本能地少放盐，但手术又贵又危险。Reflexion 的解法朴素得多：给他一本小本子，让他写下"今天盐放多了"，第二天开工前翻一翻。脑子一个字没动，手却听话了。

作者抓住的就是这个直觉：自然语言本身就是一种比标量 reward 信息密度高得多的学习信号。一句"你失败是因为没先检查肥皂是不是已经在兜里"比一个 reward=0 能教给 agent 的东西多得多。于是他们提出把环境的标量反馈翻译成一段文本反思，存进长期记忆，作为下一回合的额外上下文——一种不碰权重、只动语言的"强化学习"。

03核心问题

论文要回答的问题可以一句话讲清：一个固定权重、不可微调的 LLM agent，能不能靠"语言反思 + 记忆"这种不动权重的方式，从自己上一回合的失败里学到东西，在下一回合真正变强？

注意这里有两个关键词。第一是不动权重——它必须和传统 RL 划清界限，不能靠梯度更新作弊；第二是真正变强——不是靠偷偷塞了标准答案，而是靠环境本身给的反馈（测试通没通过、目标到没到达、答案对不对）转化出来的语言信号。这正是上一篇 Cannot Self-Correct 留下的缺口：内在自我纠正不行，那加上外部反馈行不行？

思考一下 先别往下读，凭直觉猜：让 GPT-4 写代码、写错了不让它看正确答案、只告诉它"测试没过"，再让它自己写一段"我哪儿错了、下次怎么改"的反思，第二轮重写——你觉得它能在 HumanEval 上把自己涨多少？很多人会猜"可能涨几个点"。答案是 +11 个百分点，从 80% 直接到 91%。这就是这篇论文最让人意外的地方。

04方法详解

Reflexion 的方法可以用一句话概括：把传统 RL 里"用梯度更新权重"这一步，换成"用自然语言更新一个记忆本子"。这个替换看似简单，背后是一整套重新设计的学习循环。我们分三步拆开看。

第一步：把"强化学习"重新定义成"言语强化学习"

传统策略梯度里，agent 跑完一条轨迹 $\tau$、拿到累积奖励 $R(\tau)$，然后按下面这个式子去挪动参数 $\theta$：

$$\theta_{t+1} = \theta_t + \alpha \,\nabla_\theta \,\mathbb{E}_{\tau \sim \pi_\theta}\big[R(\tau)\big]$$ (1)

Reflexion 干的事是把左边的 $\theta$ 换成一个"语言记忆" $\text{mem}$。agent 同样跑完一条轨迹、拿到奖励，但不去算梯度，而是让一个"自我反思模型"生成一段文本反思 $\text{ref}_t$，塞进记忆，下一回合的 actor 就读着这个记忆去行动：

$$\text{mem}_t = \text{mem}_{t-1} \cup \big\{\text{M}_{sr}(\tau_t,\, r_t)\big\}, \qquad a_{t+1} \sim \pi_{\text{LLM}}\!\left(s_{t+1},\, \text{mem}_t\right)$$ (2)

作者把这种自我反思式反馈称作一种"语义梯度信号"——它不像标量 reward 只能说"好/坏"，而是能给 agent 一个具体的改进方向。参数一个没动，但策略变了。这正好是上一篇指出的"内在自我纠正"缺的那块拼图：新信息从外部进入了。

第二步：四个零件，搭出一个反思闭环

Reflexion 的骨架是四个组件，全都可以用同一个 LLM 扮演，不需要额外训练任何角色：

  • Actor（行动器）：负责生成动作。输入是任务描述、当前观测、以及记忆本子；输出是一条轨迹。它在不同任务里换不同皮——决策任务用 ReAct 风格（思考/动作交替），编程任务直接生成 Python 函数，推理任务用 CoT。
  • Evaluator（评估器）：给轨迹打分，输出一个奖励信号。它就是 Reflexion 的"外部反馈入口"：编程靠跑单元测试的通/不通，决策靠有没有到达目标状态，推理靠和标准答案的精确匹配（exact match）。
  • Self-Reflection（自我反思模型）：整篇论文的核心创新。它吃进"失败的轨迹 + 奖励信号 + 已有记忆"，吐出一段文本——哪儿错了、下次该怎么改。这段文字才是真正被存进记忆、影响下一回合的东西。
  • Memory（记忆）：分两层。短期记忆是当前回合的完整轨迹；长期记忆是一个滑动窗口，装着最近几条反思文本（论文里一般留最近 3 条，受上下文长度所限）。

第三步：三种外部反馈，按任务挑着用

反思模型要生成有用的反思，前提是它能搞清楚"哪儿错了"——这本质上是 RL 里著名的信用分配问题。论文探索了三种把环境信号放大成语言反馈的方式，对应不同任务：

  • 简单的二元环境反馈：最朴素。推理任务直接看答案和标准答案精确匹配对不对，对就过、错就反思。信号最弱，但最通用。
  • 预定义启发式：决策任务里写一些"常见失败模式"的触发条件——比如同一个动作连续重复超过 3 次、或者总动作数超过 30 步，就触发反思。用来抓"卡死循环""原地打转"这类典型错误。
  • 自评估：最有意思的一种。决策任务里让 LLM 自己做二元分类判断成败；编程任务里更狠——让模型自己给自己写单元测试，跑测试当反馈。这条路线后来被证明是 Reflexion 在 HumanEval 上能打到 91% 的关键。

把这三步合起来，Reflexion 的全貌就清楚了：它没发明新模型，也没造新数据集，它造的是一种"学习协议"——一种让固定权重的 LLM agent 也能像人一样"试一次、想一下、再试一次"的协议。作者也老实承认它的代价：能力上限被 LLM 自我评估的水平卡住，也没有成功的形式化保证。但他们补了一句意味深长的话——随着 LLM 能力提升，这条路只会越走越宽。后来的事，证明他们没说错。

05实验结果

实验覆盖三类任务：顺序决策（AlfWorld 文本游戏）、编程（HumanEval）、语言推理（HotpotQA 多跳问答）。结果干净利落地回答了开篇那个问题——能，而且涨得让人意外。

任务 / 指标强基线+ Reflexion提升
HumanEval · pass@1（GPT-4）80%91%+11pt
AlfWorld · 成功率（ReAct 基线）~75%~97%+~22pt
HotpotQA · EM（ReAct 基线）~30%~51%+~20pt

最抓眼球的是 HumanEval 那一行：GPT-4 单独跑 80%，套上 Reflexion 之后 91%——套壳的打败了被套的。这在 2023 年 3 月是个炸裂的标题，因为当时 GPT-4 本身就是编程能力的天花板，一个不动权重的 wrapper 居然把它自己又抬高了 11 个点。AlfWorld 上 Reflexion 在 134 个环境、6 类任务里拿到约 97% 的成功率，比 ReAct 基线提升约 22 个百分点；HotpotQA 的精确匹配从约 30% 翻到约 51%。三个截然不同的任务（走房间、写代码、查百科），同一套框架，全面上涨。

消融：真正起作用的是那段反思，不是"再来一次"

作者做了关键的消融实验，把 Reflexion 拆开看哪块在起作用。结论很清晰：只让 agent 失败后简单重试，不写反思，几乎不涨点；真正带来增益的是那段被存进记忆的自我反思文本。换句话说，是"语言里承载的具体改进方向"在起作用，不是"多跑几遍"本身。还有一个发现尤其重要——在编程任务上，让模型自己给自己写单元测试当外部信号，比单纯看通/不通强得多，这正是 HumanEval 那个 +11 点的主要来源。

反直觉发现 还有一个让很多人意外的细节：Reflexion 的增益是逐轮累积的，但不是无限涨——一般在头几轮（论文里大多在 2-3 轮内）冲到一个高点后就平台化，甚至偶尔回落。原因是记忆滑窗塞满了，或者反思开始"原地打转"重复同一句教训。这说明语言记忆也有它的容量上限，和上下文窗口绑死是它的硬约束。

把消融和主实验放一起读，能读出这篇论文真正的主张：不是"自我纠正"没用，而是"没有外部信号 + 没有可累积记忆"的自我纠正没用。一旦把外部反馈翻译成语言、存进可跨回合读取的记忆，自我纠正立刻就活过来了——这正好从正面补上了上一篇的结论。

06影响与意义

Reflexion 的影响远超它"一个 wrapper 涨 11 点"这个表面数字。它至少做了三件大事——

第一，给"不动权重的 agent 学习"立了一个范式。在它之前，agent 要么靠 in-context 示例（一次性）、要么靠昂贵的 RL 微调（不可及）。Reflexion 证明存在第三条路：用语言当梯度、用记忆当参数、用反思当反向传播。这个范式后来被叫作 test-time learning 或 verbal RL，成了 agent 领域的基础设施级思路。

第二，把"外部反馈自我纠正"这条路彻底走通。它和上一篇 Cannot Self-Correct 形成了一对精妙的正反命题：内在自我纠正不行（反方），外部反馈 + 语言记忆就行（正方）。两篇合在一起，把整个社区的研究重心从"提示工程自我纠正"硬生生拽到了"外部反馈自我纠正"这条新轨道上。

第三，直接喂出了一整波后续工作。CRITIC 把外部反馈从"环境奖励"扩展成"工具批判"（搜索引擎、代码解释器）；Voyager 把反思升级成可复用的技能库，让 agent 在 Minecraft 里无限探索；Self-RAG 把反思和检索绑在一起。可以说 2023 年下半年那批最有想象力的 agent 论文，几乎都在 Reflexion 画的这条延长线上。

07局限性与未来方向

Reflexion 也并非没有破绽，作者自己也很坦诚。最根本的一条是：它的上限被 LLM 自我评估的能力卡死。如果反思模型本身判断错了"哪儿错了"，存进记忆的就会是一条错误的教训，下一回合不但不会进步，反而会强化错误——这是语言记忆版的"reward hacking"。论文也没有成功的形式化保证，理论上不收敛。

第二条是记忆被上下文窗口绑死。长期记忆是个滑动窗口，只能留最近 3 条左右，再多就装不下。这意味着它没法做"长期、跨任务、跨会话"的真·终身学习——它是个短期记忆型选手，不是个能记一辈子事的选手。后来的工作（比如用向量库、知识图给记忆外挂硬盘）正是在补这块。

第三条更微妙：后续研究发现，在某些任务上，Reflexion 的增益其实主要来自那个外部 Evaluator（尤其自写单元测试），反思文本本身的边际贡献没那么大——也就是说，有时是"外部信号"在起作用，不是"语言化"在起作用。这让"言语强化学习"这个故事在某些设定下没那么干净。但换个角度，这恰恰印证了 Reflexion 和上一篇共同的内核：真正要紧的是有没有外部新信息进来，至于它以语言还是以工具形式进来，是次要的。

08领域演进脉络

把本篇放回我们的演进时间线，能看到一条非常工整的"自我纠正三部曲"——

  • 第 29 篇 Self-Refine：把自我批评当成无需训练的提示工程法宝，开篇立论。
  • 第 30 篇 Cannot Self-Correct Reasoning Yet：把这块招牌砸了，指出纯内在自我纠正的增益其实是作弊。
  • 第 31 篇（本篇）Reflexion：给出正解——加上外部反馈 + 语言记忆，自我纠正立刻活过来。

但 Reflexion 的意义不止于"自我纠正"这条小线。它同时是 agent 主线上的关键一环：往回接 ReAct（Yao 等人 2022，给 agent 加了工作记忆），往前开 Voyager、CRITIC、Self-RAG（把记忆和反馈升级成技能库、工具、检索）。再往远看，这条"测试时多想一会儿、多试几遍"的思路，最终在 2024 年 9 月汇入 o1 开启的"推理范式期"——把"测试时学习"从提示工程协议升级成模型本身被 RL 训练出的能力。Reflexion 正是这条河从"提示协议"流向"RL 训练"的中途站：它先证明了"测试时学习"有用，大家才肯花大力气去把它训进权重里。

09趣味延伸

这篇论文背后有几个挺有意思的细节。第一个是血统：Reflexion 的 Actor 直接就是 ReAct，而 ReAct 的一作 Shunyu Yao 正是 Reflexion 的共同作者。所以社区里有人开玩笑说 Reflexion 全名应该叫 ReAct + reflective memory——同一个团队把自家上一作往前推了半步，从"有工作记忆的 agent"推成"有长期可编辑记忆的 agent"。这个血统也让它的叙事格外顺畅：ReAct 解决了"动起来"，Reflexion 解决了"能从失败里学"。

第二个是名字。Reflexion 是个有点复古的哲学词——它是 reflection 的古早拼法，自带"自我审视"的意味（杜威讲反思就用这个词）。但也有人说这是个双关：reflex（反射/本能）+ reflection（反思），agent "本能地反思"。不管哪种，都比直白的 Self-Refine 多了一层回味——毕竟它要强调的，正是反思要落到记忆里、能被下一回合本能地调出来，而不是想想就过。

第三个是改名史。论文 v1 的标题其实是 Reflexion: an autonomous agent with dynamic memory and self-reflection，到 v2 才改成后来广为人知的 Reflexion: Language Agents with Verbal Reinforcement Learning。这次改名不是文字游戏——团队把卖点从"动态记忆 + 自我反思"重新框定成"言语强化学习"，等于主动去坐了 RL 那把更大的椅子，宣称自己做的是"不碰梯度的强化学习"。一个标题改写，折射出这批研究者多想让 agent 圈接受"语言即梯度"这个野心。

第四个细节有点人情味。一作 Noah Shinn 投出 v1 时还是东北大学的本科生，那个 noahshinn024/reflexion 的 GitHub 仓库后来几乎成了"参考级 agent 实现"——无数人 fork 它来学怎么搭一个会反思的 agent。一个本科生的一份课程级别的工作，撞上 GPT-4 刚发布的窗口期，就成了 agent 时代最常被引用的几篇之一。AI 圈的运气和时机，有时候比什么都重要。

10个人解读与延伸思考

读这篇论文，我最想留给你的是两个判断。第一个是关于"学习"的定义放宽了。我们习惯把"学习"等同于"改权重"，所以一提 agent 学习就想到昂贵的微调。Reflexion 把"学习"重新定义成"更新任何能让下一回合行为变好的状态"——而一段自然语言记忆，恰恰是这种状态里最便宜、最可解释、最易编辑的一种。这个视角一旦打开，你会看到一堆新可能：知识库是学习、检索缓存是学习、技能库是学习——只要它能让 agent 下次更好，都算。后来 Voyager 的技能库、各种 agent 的 episodic memory，都是这个放宽定义下的产物。

第二个判断更实操：在生产里搭 agent，先问"它有什么外部反馈"。如果你只是让同一个模型回头批评自己，又没有工具、没有测试、没有检索，那就别期待增益——这是上一篇已经用数据钉死的事。但如果你能给外部信号——代码能跑、能调搜索、能查库——那就大方地用，并且给它一段可跨回合的记忆去沉淀这些反馈。Reflexion 给的不是一个算法，而是一种搭 agent 的卫生习惯：让失败被命名、被记住、被下一回合读到。光这一条，就能让你的 agent 比同行聪明一截。

留个问题给你 Reflexion 的记忆是一段自然语言，存在上下文窗口里。如果未来我们把这段记忆换成"一个向量"或者"一段可被检索的小模型参数"，它还算不算"言语强化学习"？学习的本质，到底在"用语言"这件事上，还是在"用一个可更新的外部状态"这件事上？你怎么分？

CRITIC: Large Language Models Can Self-Correct with Tool-Interactive Critiquing

Reflexion 证明了"外部反馈 + 语言记忆"能涨点，但它的外部反馈主要还是"环境奖励"——测试通没过、目标到没到。那如果反馈不是环境给的奖励，而是 agent 主动调来的工具批判呢？下一篇我们讲 CRITIC：让模型像人一样调用搜索引擎查事实、调代码解释器查 bug、调毒性 API 查安全，把 Reflexion 的"外部反馈"从"被动环境奖励"扩展成"主动工具批判"——也顺手再证一遍上一篇的结论：去掉外部工具，自我纠正立刻又瘪回去。
